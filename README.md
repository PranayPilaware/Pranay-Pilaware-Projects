# Cloud Security & Low-Latency Engineering Portfolio

Five hands-on learning projects, from a fast Nginx website to a production-style security and performance architecture. Each folder includes instructions and limits on what has and has not been deployed.

| Level | Project | Focus |
|---|---|---|
| 1 | [Fast Secure Web](01-fast-secure-web/) | Nginx, security headers, static delivery |
| 2 | [Hardened API](02-hardened-api/) | Python, non-root Docker, API health checks |
| 3 | [Secure AWS Site](03-secure-aws-static-site/) | Terraform, private S3 + CloudFront |
| 4 | [Kubernetes Secure API](04-k8s-secure-api/) | Security contexts, probes, NetworkPolicy |
| 5 | [Cloud Platform Blueprint](05-cloud-platform-blueprint/) | Threat model, WAF, performance SLOs |

**These are reproducible labs, not proof of production deployment or measured performance.** Run and test them before presenting evidence to recruiters. AWS deployment may incur charges.
